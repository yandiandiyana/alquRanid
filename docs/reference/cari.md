# Cari kata atau frasa dalam terjemahan Al-Qur'an

Mencari kata atau frasa dalam terjemahan Al-Qur'an Bahasa Indonesia.

## Usage

``` r
cari(kata)
```

## Arguments

- kata:

  Kata atau frasa yang ingin dicari.

## Value

Data frame berisi surat, ayat, dan terjemahan yang mengandung kata atau
frasa tersebut.

## Examples

``` r
cari("Allah")
#> Error in cari("Allah"): could not find function "cari"
cari("rahmat")
#> Error in cari("rahmat"): could not find function "cari"
cari("orang-orang")
#> Error in cari("orang-orang"): could not find function "cari"
```
